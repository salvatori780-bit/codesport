# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-02-06

### Added
- Interactive CV page with personal photo and downloadable CV feature
- Portfolio gallery with 6 fashion projects
- Bilingual support (English/Italian) with language switcher
- Universal image upload system with IndexedDB persistence
- Animated transitions between pages
- Minimalist editorial design with paper texture
- Project detail views with lookbooks and graphics galleries
- Credits system for projects
- Responsive design for all screen sizes

### Features
- **Projects**:
  - Gladio - Menswear Collection
  - Prigionieri - Thesis Project
  - Tabula Rasa - IED x Albini 1876 Collaboration
  - Akira - Womenswear Collection
  - Marcel - Graphic Design Project
  - Prigionieri Print Design

### Technical
- Built with React 18 and TypeScript
- Styled with Tailwind CSS v4
- Animated with Motion (Framer Motion)
- IndexedDB for client-side image storage
- html2canvas for CV export functionality
- Optimized for Vercel deployment

### Fixed
- Removed duplicate import statements in ProjectDetail component
- Fixed translation access in Akira project
- Corrected CV download functionality with oklch color conversion
- Optimized image loading and caching
