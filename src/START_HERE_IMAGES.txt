bash scripts/setup-github-images.sh


Questo è tutto! ⚡

Il comando:
1. Scarica 98 immagini PNG da GitHub
2. Le salva in public/images/projects/
3. Sostituisce TUTTI i 98 import automaticamente
4. Da: figma:asset/[hash].png
   A:  /images/projects/[hash].png
5. Crea backup di sicurezza
6. Mostra report completo

Tempo: 1-2 minuti
