Questo comando:
1. Scarica 98 immagini PNG da GitHub
2. Le salva in public/images/projects/
3. Aggiorna tutti gli import automaticamente
4. Crea backup del codice

Tempo: ~2-3 minuti

❌ Download fallisce
→ Soluzione 1: Usa Python script
→ Soluzione 2: Clona repository manualmente

Manuale:
┌──────────────────────────────────────────────────────┐
│ cd /tmp                                              │
│ git clone https://github.com/salvatori780-bit/      │
│   imagesportfoliooo.git                             │
│ cp imagesportfoliooo/"prog. figma"/*.png \           │
│   /percorso/tuo/progetto/public/images/projects/    │
└──────────────────────────────────────────────────────┘

❌ Import non aggiornati
→ Controlla che i nomi file matchino gli hash
→ Esegui manualmente find & replace:
  Trova: from 'figma:asset/
  Sostituisci: from '/images/projects/

❌ Immagini non si caricano
→ Riavvia dev server: npm run dev
→ Verifica path: /images/projects/[filename].png
→ Controlla console per errori
