bash scripts/setup-github-images.sh

OPPURE:

npm run setup-images-bash


Questo script:
✅ Clona il repository GitHub
✅ Copia tutte le 98 immagini PNG
✅ Le salva in public/images/projects/
✅ Esegue replace-imports.sh automaticamente
✅ Sostituisce figma:asset → /images/projects/
✅ Crea backup automatico
✅ Mostra report completo

Tempo: ~1-2 minuti ⚡


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  📋 METODO 2: SOLO REPLACE IMPORT (SE HAI GIÀ LE IMMAGINI)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Se hai già scaricato le immagini PNG in public/images/projects/,
esegui solo il replace degli import:

bash scripts/replace-imports.sh

OPPURE:

npm run replace-imports


Questo sostituisce:
Da:   import img from 'figma:asset/[hash].png';
A:    import img from '/images/projects/[hash].png';

File modificato: components/ProjectDetail.tsx
Backup creato:   components/ProjectDetail.tsx.backup
